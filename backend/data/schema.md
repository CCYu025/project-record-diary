# 專案紀錄 — 資料結構說明（資料契約）

> 就算這個 App 未來停用或重寫，只要這份說明、`data.json` 和 `照片/` 還在，資料就讀得懂。
> 資料的「意義」寫在這裡，不寫在程式碼裡。

## 資料放在哪裡

實際位置由 `.env` 的 `DATA_DIR` 指定：

```
<DATA_DIR>/                    例：桌面\20261012_專案紀錄
 ├─ data.json                  ← 正式資料（唯一事實來源，App 讀寫的就是這份）
 ├─ 專案紀錄_匯出.xlsx           ← 按「匯出 Excel」產生的快照，給人看的
 ├─ 工作紀錄.xlsx               ← 搬遷來源（原本手填的 Excel），App 從不改它
 └─ 照片/
     ├─ 20261012/              ← 日期資料夾，名稱 = 紀錄的 date 去掉「-」
     │   └─ S__35356682_0.jpg
     └─ _暫存/                 ← 剛上傳、還沒按儲存的照片（見下方）
```

真實資料不進 git（見 `.gitignore`）。repo 裡只有 `backend/data/example/data.json` 這份虛構的範例。

**三個格式各自獨立**：`data.json` 壞了，照片還是一般的 `.jpg`；App 停用了，`data.json` 是純文字，
任何程式都讀得開；要換工具，把 `data.json` + 這份文件 + `照片/` 整包交出去就好。

## 最外層

```json
{
  "_meta": { "schemaVersion": "1.0", "app": "專案紀錄", "savedAt": "2026-10-12T08:00:00.000Z" },
  "projects": [],
  "records": []
}
```

- `schemaVersion`：欄位有調整時往上加。讀取程式要能容忍「舊資料沒有新欄位」。
- `projects`：專案的**預設清單**（可以是空的）。畫面上的專案清單 = 實際用過的專案（最近用過的排前面）
  ＋ 這份清單。**不是固定清單**，打一個新專案名稱就會自動出現。

## `records`：工作紀錄（對應原本 Excel「工作日誌表」）

| 欄位 | 型別 | 必填 | 規則 | 原本 Excel 欄位 |
|---|---|---|---|---|
| `id` | 數字 | 是 | 遞增流水號 | — |
| `date` | `YYYY-MM-DD` | 是 | 也決定照片放在哪個資料夾 | 日期（原本填成數字 `20261012`） |
| `shift` | 字串 | 是 | `早`／`中`／`晚`（固定） | 班別 |
| `start` | `HH:MM` 或 `null` | 否 | 24 小時制 | 時間（例：`0930-1200` 的前半） |
| `end` | `HH:MM` 或 `null` | 否 | 兩個都有時不能早於 `start` | 時間的後半 |
| `project` | 字串 | 是 | 自由文字（開放清單） | 專案名稱 |
| `stage` | 字串 | 是 | 自由文字（開放清單），例：送料設備定位、配線 | 工作進度 |
| `content` | 字串 | 是 | 可以多行 | 工作內容 |
| `photos` | 陣列 | 是（可為 `[]`） | 每張 `{ "file": 檔名, "caption": 說明 }`，順序就是顯示順序 | 照片 |
| `updatedAt` | ISO 時間 或 `null` | 否 | `null` = 沒改過 | — |

**照片**：`file` 只存檔名，實際檔案在 `照片/<date 去掉「-」>/<file>`。`caption` 是那張照片的說明，
空字串 = 沒寫（說明是選填）。原本的 Excel 存的是絕對路徑，資料夾從「20261012_CCD安裝教學紀錄」
改名成「20261012_專案紀錄」之後就全部失效了——這就是只存檔名的理由。

**拿掉的欄位：設備**。原本 Excel 有「設備」欄（例：`3、4`），2026-10-12 使用者決定不要這個欄位，
舊資料搬遷時直接捨棄，不併進其他欄位。

**時段不拿來加總工時**：同一天的紀錄可能重疊，加總沒有意義。報表用「有紀錄的天數」。

**為什麼 `shift` 固定、`project`／`stage` 開放**：班別只有三種；專案和工作進度是現實世界的東西，
隨時會多一個，寫死只會一直落後。

## `照片/_暫存/`

選了照片就立刻上傳，先放在 `_暫存/`；**按儲存時**才搬進那筆紀錄日期的資料夾（同名就改成
`名稱-1.jpg`）。沒按儲存就離開的照片會留在 `_暫存/`，App 開著時每小時清一次放超過 1 小時的檔案。
`_暫存/` 裡的東西不屬於任何紀錄，整個資料夾刪掉也不會少任何資料。

**日期資料夾的檔案只有兩種情況會被 App 刪掉**：使用者在修改紀錄時把那張照片移除並儲存、
或刪除整筆紀錄——而且都要確認沒有其他紀錄也在用同一個檔案。App 不會因為「沒被參照」就自動清
日期資料夾（有些照片是 App 出現之前就放進去的）。

## 匯出的 Excel

`專案紀錄_匯出.xlsx` 有一張「工作日誌表」，欄位跟原本一樣、拿掉「設備」，共 7 欄：
日期／班別／時間／專案名稱／工作進度／工作內容／照片。照片欄只放檔名（「、」分隔），**不放說明**
（使用者 2026-10-12 決定）。這是快照，App 不會回頭讀它。
